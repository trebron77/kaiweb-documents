📁 ARCHIVAGE

Une fois complétée et signée, cette checklist doit être :

  1. Archivée en format papier dans le dossier revendeurs
  2. Scannée et sauvegardée dans le cloud (Google Drive, Dropbox)
  3. Enregistrée dans le CRM / tableau de suivi

Durée de conservation : 5 ans après la fin du contrat.
