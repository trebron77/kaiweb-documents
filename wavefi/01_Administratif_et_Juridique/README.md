# 01 — Administratif et juridique

Tout ce qui engage ou protège la société : statuts, avocat, domiciliation, banque, CDFE, assurances
et documents contractuels du SaaS.

| Sous-dossier | Contenu attendu |
|---|---|
| `1_Statuts_SASU/` | Statuts SASU, convention de compte courant d'associé, checklist des pièces à compléter, versions HTML des statuts et conventions |
| `2_Avocat/` | Demande de devis, relances, projet de statuts annoté (Cabinet) |
| `3_Domiciliation/` | Agrément, projet de contrat, pièces d'identité, échanges avec Papeete Coworking et autres prestataires |
| `4_Banque/` | Questionnaire d'ouverture de compte, documents KYC |
| `5_CDFE_JOPF/` | **À remplir** : dossier d'immatriculation, avis de dépôt, extrait JOPF |
| `6_Assurances/` | **À remplir** : RC Pro (couvrant les prestations informatiques et le traitement de données) |
| `7_Documents_Legaux_SaaS/` | CGU/CGV, DPA, cookies, mentions légales, SLA, politique de remboursement, contrat de revente revendeurs |

- `A_CGU_CGV_Clients_Finaux/` : documents destinés aux clients finaux.
- `B_Contrat_de_Revente_Revendeurs/` : contrat et annexes destinés aux revendeurs / intégrateurs.
- `C_Versions_HTML_Site_Web/` : versions HTML à publier (le `.docx`/`.pdf` de référence reste dans
  `A_` ou `B_`).

**Ne va pas ici** : les factures (→ `04_Finance_et_Comptabilite`), les one-pagers commerciaux
(→ `03_Commercial_et_Prospection`).
